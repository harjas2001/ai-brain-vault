# Epitope Mapping

## Overview
Computational and structural approaches to identifying antibody binding sites (epitopes) on antigen surfaces. Work centres on the ActiMap (ActiMapp) platform — an EGNN-based ML pipeline that predicts epitopes from antibody-antigen structure data, with a Flask web app for client delivery.
