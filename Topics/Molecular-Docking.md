# Molecular Docking

## Overview
Computational docking of antibody-antigen complexes using LightDock and related tools. Covers the full pipeline: setting up docking runs, scoring poses by binding affinity, resolving steric clashes, and filtering results. LightDock's ANM (Anisotropic Network Model) mode is used to improve flexibility.
