# Prochestra Multi-Agent System

## Overview
Prochestra is an agentic drug-discovery orchestration system built at Actimo Labs. It coordinates multiple specialised sub-agents (Boltzgen binder generation, docking, affinity scoring, referee ranking) to automate the antibody discovery pipeline end-to-end. Conversations cover architecture design (LLM vs non-LLM agents), system flowcharts, and full implementation debugging.
